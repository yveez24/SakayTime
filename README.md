# SakayTime

### A Digital Public Transportation Information and Schedule Management System

## About the Project

SakayTime is a frontend transportation information system for routes, schedules, terminals, announcements, and commuter navigation across Iloilo City and Province.

## Technologies Used

- React
- Vite
- HTML
- CSS
- JavaScript

## Project Structure

- `index.html` - Vite HTML entry point
- `src/main.jsx` - React application entry point
- `src/App.jsx` - SakayTime homepage
- `src/index.css` - Consolidated application styles
- `src/components/auth/` - Authentication dialog components
- `public/` - Static frontend assets
- `dist/` - Production frontend build output

## Installation

1. Install dependencies:

   npm install

2. Start the development server:

   npm run dev

3. Open the Vite URL shown in the terminal.

## Production

Build and preview the frontend:

- `npm run build`
- `npm run preview`
